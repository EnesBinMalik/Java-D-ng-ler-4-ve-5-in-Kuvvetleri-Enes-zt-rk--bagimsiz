# Java Döngüler: 4 ve 5'in Kuvvetleri (Enes Öztürk)

![Java Döngüler: 4 ve 5'in Kuvvetleri (Enes Öztürk) — rozet](docs/rozet.svg)

> **Java · nesne yönelimli programlama** — tasarım ve geliştirme: **Enes Öztürk**

---

Girilen sayıya kadar olan 4 ve 5'in kuvvetlerini hesaplayan interaktif Java simülatörü, döngü görselleştiricisi ve temiz kaynak kodları - Enes Öztürk.

## Öne çıkanlar

- Sınıf ve metot yapısı, kapsülleme ve kalıtım
- Döngü, koşul ve koleksiyon kullanımı
- Konsol çıktısı ve girdi doğrulama
- Arayüzde canlı simülasyon ve kaynak kod görünümü

## Kurulum ve çalıştırma

```bash
npm install
npm run dev        # http://localhost:3000
```

| Komut | Not |
| --- | --- |
| `npm install` | bağımlılıklar |
| `npm run dev` | geliştirme sunucusu |
| `npm run build` | üretim derlemesi |

## Proje yapısı

```
├── index.html

├── docs/rozet.svg        # imza rozeti
└── src/                  # uygulama kaynakları
```
